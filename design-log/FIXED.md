# FIXED - Fixed bugs (recent)

### 2026-08-09 — ~1-cent price drift Holded→WC on pull sync (v1.6.6)
**What:** Products pulled Holded→WC could land on the wrong price by exactly 1 cent on tax-inclusive setups (e.g. target 19,50€ arrived as 19,51€). Reported and diagnosed together with a cross-project investigation from hora-app (the internal ERP-writing app), which had isolated the same-class bug on the write side first.
**Root cause:** Holded's API truncates the `price` field (net) to 2 decimals in its GET response, even when the actual stored/computed value has more precision (e.g. `16,1157` stored, `"price": "16,12"` returned). This plugin's `holded_price_to_wc()` recomputed the gross as `price × (1 + tax_rate/100)` from that already-truncated net, introducing the drift (`16,12 × 1,21 = 19,5052 → 19,51`). Confirmed via a live `GET /api/v2/products/{id}` call on SKU `POG-TI-CANLO-XX-75-6`, which also showed Holded exposes the correct full-precision gross directly in a separate `total` field (`"total": "19,50"`).
**How:** `holded_price_to_wc()` (`includes/class-cthls-sync.php`) now prefers Holded's `total` field (rounded to 2 decimals) as the WC price when tax-inclusive pricing is enabled and the product is taxable, instead of recomputing from `price`. Falls back to the previous recompute logic when `total` is absent/empty or when WC is configured tax-exclusive (net `price` is used as-is in that case, unchanged). Both call sites in `holded_product_to_wc()` (variation and simple-product branches) now pass `$holded_product['total'] ?? null` through.
**Files:** `includes/class-cthls-sync.php`, `carttrigger-holded-sync.php` (v1.6.6), `readme.txt`, `README.md`
**Notes:** hora-app flagged that Holded's `total` field can be briefly stale (a few seconds) right after another system writes a price update — a propagation-lag/timing concern, not a precision one. Not addressed here (out of scope for this fix; would need retry/delay logic if this plugin ever polls right after its own push). Validated live: SKU `POG-TI-CANLO-XX-75-6` — before fix WC 19,51€ vs Holded 19,50€; after deploying v1.6.6 and re-pulling, WC correctly shows 19,50€.
